# Dr. Unnati Kothari Physiotherapy Website

Static one-page website for Dr. Unnati Kothari's home physiotherapy visits in Nashik, Maharashtra and online consultation.

## Local preview

Open `index.html` in a browser.

## Free hosting with GitHub Pages

1. Create a new GitHub repository, for example `unnati-physiotherapy`.
2. Push these files to the repository's `main` branch.
3. In GitHub, open **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select branch **main** and folder **/**, then save.
6. GitHub will publish the site at a URL like:
   `https://<github-username>.github.io/unnati-physiotherapy/`
